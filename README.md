# packet-sniffer
a python based packet sniffing and network traffic analysis project developed for learning and understanding network communication and cybersecurity concepts.

## Features

- Capture IP network packets using scapy
- displays source and destination IP addresses
- Identify TCP & UDP protocols
- classify other IP traffic
- Inspect basic packet information
- Perform basic network traffic analysis
- capture up to 20 packets per execution

## Technologies Used

- Python
- Scapy
- TCP/IP
- Computer Networking
- Cybersecurity

## Installation

git clone https://github.com/SuryaHarsha2/packet-sniffer.git
