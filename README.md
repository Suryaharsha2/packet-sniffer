# packet-sniffer
a python based packet sniffing and network traffic analysis project developed for learning and understanding network communication and cybersecurity concepts.

## Features

- Capture network packets
- Analyze source and destination IP addresses
- Identify network protocols
- Display source and destination ports
- Inspect basic packet information
- Perform basic network traffic analysis

## Technologies Used

- Python
- Scapy
- TCP/IP
- Computer Networking
- Cybersecurity
